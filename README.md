# 🚀 Core Java & Problem-Solving Mastery (60+ Programs)

Welcome to my Java learning and practice repository! This repository contains **over 60 Java programs** built while mastering Core Java concepts, logic building, Object-Oriented Programming (OOP), and building interactive console-based applications.

---

## 📌 About This Repository

This repository tracks my hands-on journey with Java—from basic syntax and mathematical algorithms to structured CRUD applications. Every program is designed to solve specific logic problems or demonstrate key Java language features cleanly and efficiently.

---

## 📚 Topics & Concepts Covered

### 1. Java Fundamentals & Control Flow
* **Variables & Data Types:** Working with primitives (`int`, `double`, `boolean`, `char`) and reference types.
* **Input / Output Handling:** Using `Scanner` for interactive user inputs and buffer management.
* **Operators:** Standard practice with arithmetic, relational, logical, assignment, and ternary operators.
* **Conditional Logic:** Implementing decision-making using `if-else`, nested conditions, and `switch-case`.
* **Loops & Iteration:** Standard and nested `for`, `while`, and `do-while` loops with `break` and `continue`.

### 2. Logic Building & Algorithmic Practice
* **Mathematical Operations:** Prime numbers, Fibonacci series, factorials, Armstrong numbers, Palindrome checks, and GCD/LCM.
* **Pattern Printing:** Creating dynamic shapes, star pyramids, number triangles, and inverted patterns using nested loops.

### 3. Arrays & String Manipulation
* **1D & 2D Arrays:** Array traversal, linear search, finding min/max values, array reversal, and matrix manipulations.
* **String Operations:** Immutability, string formatting, parsing, and built-in methods (`.length()`, `.charAt()`, `.substring()`, `.equalsIgnoreCase()`, `.indexOf()`).

### 4. Object-Oriented Programming (OOP)
* **Classes & Objects:** Creating class blueprints, defining attributes, and object instantiation.
* **Constructors & Methods:** Parameterized constructors, modular helper functions, passing objects as parameters, and method signatures.
* **Encapsulation:** Restricting data access using `private`/`public` modifiers and object state encapsulation.

### 5. Collections Framework & CRUD Operations
* **Dynamic Collections:** Using `java.util.ArrayList` for dynamic data management.
* **Built-in Functions:** Efficient searching, updating, and removing items using methods like `.removeIf()`, `.forEach()`, and Stream API methods (`.filter()`, `.findFirst()`).
* **Console Applications:** Complete **C**reate, **R**ead, **U**pdate, and **D**elete implementations.
